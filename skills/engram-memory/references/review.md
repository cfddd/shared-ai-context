# 证据复核与修订

只在用户明确要求复核、纠错或整理记忆时使用，范围限于当前任务或指定主题。

用户仅要求复核时，只报告发现和证据缺口，不写数据库。用户明确要求写回整理或纠正结果时，已授权按 [主 Skill 的准入与保存操作](../SKILL.md) 更新，无需例行再确认。

1. 定位相关条目，读取旧内容的完整正文；按需追到原始引用。
2. 核对必要的已有证据，例如真实工具结果、用户反馈、提交、报告或可读会话片段。优先保留引用，分清实际观察与其解释。
3. 纠正错误、限定适用条件，保留仍有效的信息，合并重复表达。来源不可用时标明缺口；不以多个摘要相互引用或重复次数提升可信度，缺少证据的判断仍是待确认假设。
4. 仅复核时报告结果；已授权更新且内容有变化时，同 topic 保存完整当前结论，沿用 Engram 的旧版本机制。无变更则不重写。

多 Agent 按条目分工；同一 topic 交给一个维护者汇总，避免并发覆写。此入口由本次用户指令触发，不在后台运行，也不收集全量会话日志。
