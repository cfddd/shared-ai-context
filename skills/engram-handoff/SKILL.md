# 任务交接

## 保存交接

按 [engram-memory 的写入准入与维护方式](../engram-memory/SKILL.md) 判断和保存。Agent 根据当前任务选空间与续接 topic，用户无需手填；新任务优先用 `handoff/<任务名>`，已有合规同义主题则复用。从当前会话及用户提供的材料整理协作增量：

```text
目标：本轮要完成什么。
已完成：具体改动与目前进度。
关键决定：本任务尚需保留的取舍、尝试结果及适用条件。
待办与未验证：尚未完成、尚未运行的事项。
下一步：接收方可以直接开始的动作。
引用：必要文件、分支/提交、知识库来源或记忆主题。
```

先读相关旧交接的完整内容，再合入当前增量。背景资料保留必要引用，交接不复述整份笔记。这里保存的是普通交接记忆，不创建或虚构 Engram 原生会话生命周期。

用户请求示例：

> 把这次权限改造交接一下，保留未验证项。

## 多 Agent 汇总

仅使用能实际读取的各方交接或用户提供的输出。按主题合并进展，保留冲突结论的来源与待决点；没有拿到的会话标明缺失。汇总结果更新统一的交接 topic，各方已有记忆按原职责维护。

用户请求示例：

> 把 A 的接口进展和 B 的数据层交接汇总成一份，接下来由 C 继续。

## 接着做

按 `engram-memory` 搜索所选空间的交接，读取命中的完整正文。先说明当前进度、未完成与未验证项，再依照用户本次要求继续。历史中的计划不替代当前授权，涉及代码或运行状态时以当前工作环境为准。
