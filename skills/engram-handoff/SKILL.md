# 任务交接

## 保存交接

确定 Engram 空间和稳定主题 `handoff/<任务名>`。从当前会话及用户提供的材料整理：

```text
目标：本轮要完成什么。
已完成：具体改动与目前进度。
关键决定：当前采用的方案及必要原因。
待办与未验证：尚未完成、尚未运行的事项。
下一步：接收方可以直接开始的动作。
引用：必要文件、分支/提交、知识库来源或记忆主题。
```

通过 `engram-memory` 的 CLI 保存操作写入同一 topic；内容变化时更新该主题。这里保存的是普通交接记忆，不创建或虚构 Engram 原生会话生命周期。

用户请求示例：

> 把权限改造交接到 work-risk-platform，主题 handoff/permission-refactor，保留未验证项。

## 多 Agent 汇总

仅使用能实际读取的各方交接或用户提供的输出。按主题合并进展，保留冲突结论的来源与待决点；没有拿到的会话标明缺失。汇总结果更新统一的交接 topic，各方已有记忆按原职责维护。

用户请求示例：

> 把 A 的接口进展和 B 的数据层交接汇总到 handoff/permission-refactor。

## 接着做

按 `engram-memory` 搜索所选空间的交接，读取命中的完整正文。先说明当前进度、未完成与未验证项，再依照用户本次要求继续。历史中的计划不替代当前授权，涉及代码或运行状态时以当前工作环境为准。
